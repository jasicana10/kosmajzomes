# Kosmaj Zomes — sajt

Statični sajt, spreman za GitHub Pages.

## Postavljanje
1. Napravite repozitorijum na GitHubu i prebacite sadržaj ove fascikle u koren (index.html, support.js, assets/).
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Sajt će biti dostupan na `https://<korisnik>.github.io/<repo>/`.

## Napomena o video snimcima
Snimci na naslovnoj sekciji učitavaju se sa spoljne adrese (CloudFront). Ako te adrese jednog dana prestanu da rade, prebacite mp4 datoteke u `assets/` i zamenite `src` vrednosti u `index.html`.
